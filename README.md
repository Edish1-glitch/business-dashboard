## 🤔 מה הבעיה שזה פותר?

לכל עסק קטן ולכל עצמאי יש את אותו כאב ראש: **חשבוניות מפוזרות בכל מקום** — במיילים, בצילומים בטלפון, ב-PDF-ים בהורדות. בסוף החודש צריך לאסוף הכל ידנית, להקליד סכומים, ולשלוח לרואה החשבון. משעמם, לוקח זמן, וקל לפספס.

**FinDash עושה את זה בשבילך:** מחבר את המייל, שולף את החשבוניות אוטומטית, קורא מהן את הפרטים (ספק, סכום, תאריך), ומחכה רק שתאשר בלחיצה. את המאושרות אפשר לשלוח לרו״ח ישירות מהאפליקציה.

## 🚀 איך זה עובד (בקצרה)

```
1️⃣  מחברים את ה-Gmail        →   2️⃣  FinDash מזהה חשבוניות אוטומטית
                                          ↓
4️⃣  שולחים לרו״ח בלחיצה      ←   3️⃣  מאשרים / מסמנים עסקי-פרטי
```

1. **חיבור** — מחברים חשבון Gmail אחד או יותר (מאובטח עם Google OAuth).
2. **זיהוי** — האפליקציה שולפת ומזהה חשבוניות אוטומטית, גם בסריקת רקע.
3. **אישור** — עוברים על מה שהתקבל, מתקנים אם צריך, ומסווגים עסקי/פרטי.
4. **שליחה** — שולחים לרו״ח או מייצאים ל-CSV. הכל נשמר ומרוכז.

> אפשר גם פשוט **לצלם או לגרור קובץ** להעלאה ידנית — והאפליקציה תזהה את הפרטים באותה צורה.

## 🛠️ מאחורי הקלעים (לטכנופילים)

| שכבה | טכנולוגיה |
|------|-----------|
| **Frontend** | Next.js 16 (App Router) · React · Tailwind CSS v4 · עיצוב "Liquid Glass", RTL, מובייל-פירסט |
| **Backend** | Next.js API Routes · Prisma 7 |
| **Database** | PostgreSQL (Neon, ענן) |
| **אחסון קבצים** | Cloudflare R2 (S3-compatible) |
| **התחברות** | NextAuth v4 + Google OAuth |
| **זיהוי טקסט** | Tesseract OCR (עברית+אנגלית) · Poppler · pdfjs |
| **מייל** | Gmail API |
| **התראות** | Web Push (VAPID) + Service Worker |
| **אירוח** | Oracle Cloud (Docker + Caddy), עם סנכרון רקע דרך GitHub Actions |

זה **PWA** מלא: מתקינים למסך הבית, עובד אופליין-פרנדלי, עם התראות דחיפה אמיתיות באייפון ובאנדרואיד.
